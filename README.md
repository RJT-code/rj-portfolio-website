# RJ Portfolio Website

A personal portfolio website built on a minimal, production-ready Next.js foundation.

## Technology stack

- Next.js App Router
- React and TypeScript
- Tailwind CSS
- ESLint
- npm

## Prerequisites

- Node.js 20.9 or newer
- npm 11 or a compatible npm release

## Setup and development

Install dependencies and start the local development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validation

```bash
npm run lint
npm run typecheck
npm run build
```

Run the production server after a successful build with `npm start`.

GitHub hosting and Vercel deployment are planned but are not configured yet.
